### Status Codes:
- 200 - Ok
- 201 - Created
- 400 - Bad Request
- 401 -  Unauthorised
- 403 - Forbidden
- 404 - Not Found

## Content Type:
- text/html  -> For HTML live server
- text/json  -> For JSON file type
- text/plain -> For plain text file
