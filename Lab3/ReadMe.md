# HTTP MODULE
- ### HTTP: Hyper Text Transfer Protocol
- ### HTML: Hyper Text Markup Language
- ### CSS: Cascading Style Sheet
- ### npm: Node Package Manager
## 
### Status Codes:
- 200 - Ok
- 201 - Created
- 400 - Bad Request
- 401 - Unauthorised
- 403 - Forbidden
- 404 - Not Found

## Content Type:
- text/html  -> For HTML live server
- text/json  -> For JSON file type
- text/plain -> For plain text file
## Server can send data:
1. 
2. html
3. json data
4. plain text
5. css
6. js
7. file
## Server can set Header to send data:
1. res.writeHeader( )
2. res.setHeader( )
## Sever can set status code:
1. res.statusCode( )
2. res.writeHeader( )
## Request Methods:
1. get
2. post
3. put/patch
4. delete
